# Jadoo React Landing Page

A responsive React + Vite implementation inspired by the supplied Jadoo travel landing-page screenshot.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code / terminal.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the localhost URL printed by Vite.

## Included
- Responsive navigation with mobile menu
- Hero section, service cards, destination cards
- Booking steps and trip cards
- Interactive testimonial slider
- Email subscription form with client-side success state
- Demo modal
- Smooth scrolling

Images are loaded from Unsplash, and Google Fonts are loaded online. Replace those URLs with local assets if you need an offline build.
