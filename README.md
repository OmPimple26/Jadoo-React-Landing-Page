# ✈️ Jadoo – Travel Landing Page 🌍

A modern, responsive travel landing page built with **React, JavaScript, and CSS**, inspired by the Jadoo travel website design. Discover beautiful destinations and explore a clean, user-friendly travel experience.

## 🚀 Live Demo

🔗 **Live Website:** [View Jadoo Landing Page](YOUR_DEPLOYMENT_URL_HERE)

## 📸 Features

- 🏠 **Hero Section** – Attractive headline and call-to-action buttons.
- 🧭 **Responsive Navigation** – Easy navigation with a mobile-friendly menu.
- 🌤️ **Travel Services** – Explore weather, flights, local events, and customization services.
- 🏛️ **Top Destinations** – Beautiful destination cards with images and trip details.
- 🧳 **Booking Steps** – Simple three-step trip planning section.
- 💬 **Testimonials** – Interactive testimonial slider.
- 📩 **Newsletter Subscription** – Email input with a success message.
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- ✨ **Smooth Scrolling** – Smooth navigation between page sections.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Language:** JavaScript (JSX)
- **Styling:** CSS3
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Fonts:** Google Fonts
- **Images:** Unsplash

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/jadoo-react-landing-page.git
```

### 2. Navigate to the project folder

```bash
cd jadoo-react-landing-page
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### 5. Create a production build

```bash
npm run build
```

The production-ready files will be generated in the `dist` folder.

## 🌐 Deployment

This project can be deployed using **Vercel**.

1. Push the project to GitHub.
2. Sign in to [Vercel](https://vercel.com/).
3. Import your GitHub repository.
4. Use the following build settings:

   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`

5. Click **Deploy**.
6. Add your live deployment URL in the [Live Demo](#-live-demo) section above.
